# Coursework Arkanoid

## Шрифт
В игре есть счетчики жизней и очков. Я использовала шрифт https://fonts-online.ru/fonts/lcd5x8h/download. Можно любой другой. Очень желательно указать верный путь к файлу со шрифтом. Просто с текстом намного понятнее, что происходит в игре.

## Библиотеки
Для игры использовалась библиотека SFML. Скачивала с https://github.com/SFML/SFML/releases/tag/2.6.1 (Assets -> SFML-2.6.1-windows-vc17-64-bit.zip) (также можно скачать с официального сайта, но у меня не грузился zip оттуда).

Шаги:
подключить include и lib SFML в проект
скопировать DLL из bin в папку с .exe
выполнить сборку проекта
запустить программу

## Особенности реализации
### Механика
1) Управление - стрелками.
2) Мяч отражается от стен, блоков и каретки.
3) Когда мяч падает мимо каретки, снимается одна жизнь + снимается 1 балл + каретка возвращается к исходному размеру + скорость шарика сбрасывается до начальной.
4) Жизни кончились - поражение. Все блоки разрушены - победа.

### Блоки
1) Есть неразрушимые блоки (серые). От них мяч просто отскакивает. 
2) Есть блоки с бонусами (циановые). При попадании они разрушаются и из них выпадает бонус (таким образом, у блока 1 жизнь)
3) Есть блоки-ускорители (жёлтые). При попадании они ускоряют и разрушаются (у блока 1 жизнь).
4) Есть блоки, с большим уровнем здоровья (малиновые). Для разрушения нужно попасть в них 5 раз. По мере снижения их "прочности" будет меняться их цвет.
5) Попадание в блок -> +1 очко
   
### Бонусы
1) Увеличение скорости мяча (жёлтый бонус-ромбик)
2) Увеличение размера каретки (зелёный бонус-ромбик)
3) Прилипание шарика к каретке (фиолетовый бонус-ромбик). Для отлипания нажмите пробел.
4) Одноразовое дно для шарика (синий бонус-ромбик). Формально - "щит" на 1 жизнь.
5) Второй шар (белый бонус-шар). ПУНКТ 9. Нужно словить бонус, который сразу добавит на поле шар, способный оттолкнуться и от первого, и от блоков. Изначально бонус летит в форме шара, чтобы нельзя было его спутать с "обычными" бонусами.
